# 3. Paper audit, baselines and labour-onset (DOS) prediction

My additions to the published SIMCO pipeline (lab code: github.com/ofondeur/SIMCO). These scripts sit next to the
SIMCO repository's `cellot/`, `stablVMax/` and `stabl_launch/` and import them; they were run on the lab's data on the
Sherlock cluster (paths point to `/scratch/users/bmerwan/...`). No data is included.

## What is here

| folder | what it does |
|---|---|
| `stabl_launch/` (new scripts only) | Reproduction and audit of the paper's Fig 5b (Stabl + XGBoost, 100 splits by woman). `aligned_rescore.py` is the **row-order bug fix**: the lab's rescore script misaligned prediction rows and patients, so 94 % of test samples had the same woman in training (inflated the non-CellOT arms by up to +0.08 R²). `null_maps_*` = untrained / mismatched maps as features; `paper_protocol*` and `simq_*` = feature-set arms on the paper's exact protocol; `clinical_baselines.py` = gestational age alone; `drug_*` = audit of the drug arm (Fig 5d/e/g) with TreeSHAP attribution. `lab_scripts_cli_options.patch` = the small CLI options I added to two lab scripts (n_splits, outcome column, feature blocks). |
| `baselines/` | Closed-form maps to benchmark CellOT (`baselines.py`: median shift, quantile map, Gaussian OT, with `test_baselines.py` on known maps), the noise floor between control wells, the checkpoint-selection leak (`selection_leak.py`), replay of the paper's pair-selection rule, drug maps without a neural network (`gauss_drug_maps.py`, quantile maps on features), measured distributional features (`distrib_features.py`), simulated quantiles. |
| `ml_dos/` | Supervised DOS prediction from the **measured** resting cells only (no simulation): ~8,300 features per visit, ~25 learners (linear, kernel, boosting, MLP / deep nets, DeepSets on raw cells, super learner), model chosen inside each of the paper's 100 splits. |
| `notebooks/` | Each notebook is generated by its `build_*.py` (outputs stripped here): `stabl_results` (reproduction), `cellot_vs_gaussot`, `quantiles`, `ml_dos_supervised`, `drug_map_choice`, `summary_all_results`, ... |

## Main results (paper protocol, 100 splits by woman, bug fixed)
- Reproduction of Fig 5b: R² 0.415, RMSE 24.1 days, 21 features (exact).
- Baselines on the same protocol: untrained random ICNN 0.33, maps of the wrong stim / cell type 0.34, measured resting
  cells only 0.40, Gaussian OT 0.40, CellOT 0.42.
- CellOT + measured features + simulated quantiles + correlation filter: 0.49 (22.3 days).
- Dense supervised model on the measured cells only: **R² 0.545, 21.0 days**, better than the paper in 67/100 splits
  (Holm p 0.006). The gain comes from using the measured distribution richly, not from the simulation.
- Drug arm: per-marker quantile maps beat CellOT drug maps on held-out donors (19/20 donor-repeats), give 4× fewer
  implausible treated women and cost ~800× less compute.
